# Polices locales

Uniquement des fichiers locaux sous licence libre (SIL Open Font License), chacun accompagné de sa licence nommée `<Famille>-OFL.txt`. `npm run verify` refuse une police sans licence.

| Fichier | Licence | Source |
|---|---|---|
| `Baloo2-Variable.ttf` | `Baloo2-OFL.txt` (OFL 1.1) | https://github.com/google/fonts/tree/main/ofl/baloo2 |
| `Nunito-Variable.ttf` | `Nunito-OFL.txt` (OFL 1.1) | https://github.com/google/fonts/tree/main/ofl/nunito |

Fichiers repris à l'identique du projet Englizy (mêmes empreintes SHA-256). Le choix définitif des polices reste ouvert : voir `docs/vision.md`.

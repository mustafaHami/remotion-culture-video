# tests

Tests `node:test` lancés par `npm test` (fichiers `*.test.cjs`). Ils couvrent les règles du dépôt et la synchronisation des skills. Les tests de schéma d'épisode et de narration s'ajouteront avec le premier flux de création.

Un test réussi ne valide pas une vidéo : voir la section « Vérifications » d'`AGENTS.md`.

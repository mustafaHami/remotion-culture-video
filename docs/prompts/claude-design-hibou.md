# Prompt Claude Design : refonte du hibou explorateur

Rédigé le 25 octobre 2026, après l'essai de styles. À envoyer dans la même conversation Claude Design que les directions de style : le contexte du projet y est déjà.

```text
Le hibou actuel est rejeté : trop rectangulaire, on dirait un Lego. Le décor en voxels, lui, est validé et reste tel quel.

Propose 3 versions du hibou, plus organiques et attachantes, de la plus « voxel » à la plus douce :
1. voxels fins (3 à 4 fois plus de détail, volumes arrondis) ;
2. blocs adoucis (arêtes arrondies, comme du bois poli) ;
3. personnage lisse et stylisé (formes rondes, ombrage doux) posé dans le décor voxel.

On garde : grands yeux ambrés expressifs, aigrettes, sacoche, loupe ; silhouette lisible en petit ; aucune ressemblance avec un hibou de marque connue.

Pour chaque version : face, trois quarts et profil ; 5 poses (intrigué, montre de l'aile, réfléchit loupe levée, surpris, salue) ; le hibou à côté de l'immeuble voxel ; ses couleurs en A, B et D.

Contrainte : il sera reconstruit en code avec Three.js à partir de formes simples (sphères, capsules, cônes, voxels), en pièces animables (tête, paupières, ailes, corps). Indique les proportions principales.

Termine par un court comparatif : charme, lisibilité, cohérence avec le décor, facilité d'animation.
```
